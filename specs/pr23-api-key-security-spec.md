# PR-23：API KEY 安全与渐进迁移

日期：2026-10-29。状态：产品决策及实施计划已批准；PR-23a 后端已实现并通过一次独立评审（1 项 Important 已修复、8 项 Minor 留档，见 `specs/pr23-api-key-security/STATUS.md`），PR-23b 面板未实施。生产已于 2026-10-30 初始化（7.6.3，off + 全权限 key）；off 宽限语义修正（7.6.4）实施中。

本文件取代 `docs/API-KEY-SECURITY-PLAN-2026-10-29.md` 中与之冲突的建议。

## 已批准的产品决策

1. KEY 只在生成成功时展示、复制一次；以后不能找回，只能吊销、重新生成。
2. 分阶段收紧：管理能力上线（不改变匿名调用）→ 客户端配 KEY → 池强制 → 全局强制。
3. Dashboard 新增独立「密钥」页。
4. 全局强制须迁移核对后单独获得用户确认。部署管理功能不等于授权启用强制。

## 安全要求

- API KEY 使用 `secrets.token_urlsafe(32)` 等价的至少 256 位随机熵；显示名不参与密钥生成。
- 只持久化 KEY 的 SHA-256 摘要及 id/name/scope/created_at/expires_at/revoked_at；禁止保存可还原原值。
- 原值仅在已验证管理会话下的创建响应返回一次；响应 `Cache-Control: no-store`；不进入日志、URL、浏览器持久存储或异常文本。
- 控制台密码由 CLI 首次设置/重置，避免匿名网页抢注首次密码；加盐 scrypt 存储，文件权限 0600，常数时间比较。
- 浏览器不保存密码。短时随机管理会话仅存内存，Cookie 为 HttpOnly + SameSite=Strict，生产 HTTPS 使用 Secure；本机 HTTP 仅绑定 loopback。会话最长 15 分钟、不滑动续期，重启失效。
- 登录及写接口校验 Host、Origin 与 CSRF；不开放跨源 CORS。仅允许部署配置明确列出的可信来源；缺少/不匹配 Origin 的浏览器写请求拒绝。
- 登录失败总量限速 5 次/分钟，先限速再计算 scrypt；密码修改后旧会话失效。审计不包含密码/KEY/会话令牌。
- 创建、吊销、策略切换均需管理会话及 CSRF；列表也需登录；继承既有 admin token 外层守卫，不能依赖 localhost 等于可信用户。
- 一份新式安全存储同时保存 KEY 摘要和 enforcement=off|pools|all；写入需串行事务、原子提交，写失败不发布新内存状态。
- 已启用策略后存储损坏/丢失不得退回匿名开放；热加载保留最后有效快照并报错，冷启动配置错误拒绝服务就绪。恢复通过受控 CLI，而不是删文件开放。

## 鉴权兼容架构

现有 `AuthManager` 保存明文 KEY；不能用它存摘要，也不能把新 KEY 双写入旧 YAML。

新增安全鉴权 facade，保持消费者依赖的 `enabled/check/key_name/reload` 接口，在 `proxy_manager.py` 构造时注入；`proxy/auth.py` 和转发核心保持不变。新功能初始化前验证所有消费者的接口兼容性。

facade 在自身启用时使既有检查点始终执行，`check` 再按策略决定匿名是否放行：
- off（迁移宽限，7.6.4 起）：匿名池/直连允许；未注册/过期凭证**放行并记 warning**（避免激活瞬间打挂带占位 key 的存量客户端，2026-10-30 事故）；吊销与 scope 边界在 off 下**始终生效**；合法新 KEY 仍校验 scope/有效期并记使用者。
- pools：匿名 `iff/<pool>` 拒绝，匿名直连允许。
- all：全部推理端点匿名拒绝。
- scope 按原始逻辑模型名校验，不能让池权限自动扩展到直连候选或其他池。
- 旧 `api_keys.yaml` 如已开启，保持原有强制范围，绝不能被 off/pools 降级；迁移期接受旧 KEY，但保持原权限。不自动删除或转换旧凭证。
- 吊销立即影响后续请求；不承诺中断已经开始的推理。

## 界面

独立「密钥」页：登录、策略状态、列表、创建（名字/模型池权限/全模型/有效期）、一次性显示复制、吊销确认、匿名调用迁移提示。无 reveal 接口、无找回按钮。

迁移提示不把“最近 24h 匿名为零”等同于迁移完成；结合低频客户端清单。分类器、bench、CLI/agents 等内部调用者必须点名核对。第一版不提供无确认的全局强制快捷按钮。

## 交付边界

PR-23a：摘要存储、兼容鉴权、控制台密码与会话、管理 API/CLI、默认 off。
PR-23b：独立面板与真实浏览器交互门禁。
后续运维：分发 KEY、迁移客户端，分别授权开启 pools/all；生产密码、KEY 均不得输出到对话。

Python 3.10+，vLLM 0.24 不升级，sandbox-first；跨评审使用一次 fresh-context subagent。补丁版本在各交付时按实际 main 递增。
